# Canonical product metadata

Use these values for every future build, App Store Connect upload, website listing, and localized store submission.

- Product name: `CloudBridge: SFTP Transfer`
- Executable name: `CloudBridge`
- Bundle identifier: `com.dazhang.CloudBridge`
- English search phrases: `SFTP file transfer,SSH download manager,remote server files,macOS file download,server preview`
- Simplified Chinese search phrases: `SFTP文件传输,SSH远程下载,远程服务器文件,macOS下载管理,服务器文件预览`

The product name and bundle identifier are intentionally different. Never rename the executable or bundle identifier when optimizing store search metadata.
