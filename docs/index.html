Browse, preview, and download

Use CloudBridge as a remote file browser for your SSH/SFTP server. Browse remote folders, preview files with Quick Look, and download files or folders directly to your Mac.

It is useful for VPS file management, NAS SFTP access, developers, and system administrators who need a focused SFTP download manager without an account or cloud middleman.
