CloudBridge Support

Support page for CloudBridge 1.0 on macOS.

About CloudBridge

CloudBridge helps you connect to your own SSH/SFTP servers, browse remote folders, preview files with Quick Look, and download files or folders to your Mac.

Common Questions

Do I need a CloudBridge account?
No. CloudBridge connects to servers that you provide and control.

Where are passwords stored?
Saved server passwords are stored securely in macOS Keychain and are retrieved locally when CloudBridge connects to that server. Credentials are used for password authentication to the SSH/SFTP server you select, not sent to the developer or CloudBridge services. The password is sent only to that server through SSH.

How do I remove saved credentials?
Disconnect, edit the server, and choose Remove Saved Password. Deleting a server removes its locally saved configuration and Keychain credential.

Why do folders show size as -?
Remote directory sizes can be misleading on SFTP servers, so CloudBridge shows - for folders instead of a fixed placeholder size.

Before Requesting Support

  • Confirm the server host, port, username, and authentication method are correct.
  • Confirm the server supports SFTP access.
  • Check whether your network, firewall, or cloud provider security group allows SSH/SFTP connections.
